# World Book Editor — Lore Atlas V2 Visual Contract

## Concept

A private **lore atlas and editorial archive**: the world itself is the protagonist, while controls behave like quiet indexing instruments around it.

## Primary protagonist

The active world book and its entries — not the application logo and not a dashboard of metrics.

## Secondary interest layers

1. Archival indexing: entry numbers, thin rules, taxonomy labels and status marks.
2. Cartographic cues: forest/ochre/indigo accents, line systems and atlas-like framing.
3. Editorial working notes: serif content, compact mono metadata, AI/tool traces as annotations.
4. Material depth: warm ivory paper, restrained grain, translucent sticky surfaces only where interaction benefits.

## Typography

- Display/content: editorial serif with CJK serif fallback.
- Controls/navigation: neutral system sans.
- UID, token, tool and machine metadata: monospace.
- Large type is reserved for world identity and entry titles; operating chrome stays compact.

## Material / surface language

Warm archival paper, technical index lines, ink-like text, restrained translucent layers. Avoid generic glass cards and SaaS panel stacking.

## Color and light

- Dominant: warm ivory / parchment.
- Structural accent: deep forest green.
- Editorial/index accent: ochre/brass.
- Secondary semantic accent: muted indigo.
- Wine is retained for destructive/legacy semantic continuity but is no longer the identity color.
- Dark mode remains warm charcoal paper rather than a black console.

## Project-specific motif

**Atlas index line**: short ochre lead-in rules, entry numbering, thin registry lines, and metadata set as archival annotations.

## Composition

Desktop becomes a dense editorial workspace instead of a centered phone frame:

- persistent left rail;
- world overview column + entry field on the Library screen;
- writing canvas + sticky inspector in the Editor;
- centered long-form AI working document with an anchored composer;
- archive grid scales to available space.

## Motion language

Precise / quiet / layered / mechanical.

Movement communicates hierarchy and state: small translations, rule expansion, soft depth changes. No ornamental continuous loops.

## Density target

**Rich workspace with quiet reading zones.** Density concentrates in index/navigation/metadata; entry prose and AI prose get wider measures and calmer spacing.

## Responsive transformation

Desktop uses a left rail and multi-column working surfaces. Mobile restores a bottom navigation, collapses editor controls into the existing sequential flow, converts dialogs to bottom sheets, and prioritizes readable content over persistent metadata.
